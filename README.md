# AIGC Video Prompt Director（AIGC 视频提示词导演）

基于"十层焚决"方法论的 AIGC 视频提示词生成 Skill，将模糊的视频创意逐层拆解为高质量、可执行的结构化分镜提示词。

## 方法论来源

本 Skill 的核心方法论提炼自 244 篇 AIGC 提示词教程和 1013 条提示词的深度分析，抽象为"十层焚决"体系。

## 十层焚决

| 层级 | 名称 | 解决的问题 |
|-|-|-|
| 1 | 需求定魂诀 | 这条视频到底为谁解决什么问题 |
| 2 | 画面拆骨诀 | 把抽象风格拆成主体、环境、构图和空间 |
| 3 | 光影塑形诀 | 让光源、阴影、反射和材质统一 |
| 4 | 镜头定距诀 | 用景别、焦段、机位控制心理距离 |
| 5 | 运镜造实诀 | 用路径、视差、惯性和遮挡制造真实运动 |
| 6 | 动作生因诀 | 让动作有原因、有阶段、有身体联动 |
| 7 | 多主体锁定诀 | 解决多人、多产品、多元素互相干扰 |
| 8 | 产品可信诀 | 让商业产品结构正确、卖点清楚、接触真实 |
| 9 | 提示词编译诀 | 把创意翻译成模型能执行的结构化指令 |
| 10 | 工作流复盘诀 | 用拆分、筛选、质检和迭代提高成片率 |

## 核心理念

**提示词不是形容词，而是约束系统。**

## 功能特点

- **完整引导流程**：从模糊想法到可执行分镜，4 轮对话完成
- **中英双语输出**：中文提示词 + 英文提示词，适配所有主流 AIGC 视频工具
- **场景自适应**：自动识别视频类型（产品/叙事/品牌/人物/多角色），调整侧重层
- **内嵌质检**：10 条终极检查表，自动标注薄弱项
- **丰富案例库**：9 类 Badcase→Goodcase 对比，校准输出质量

## 适用工具

- 中文：即梦、可灵、Pixverse
- 英文：Runway、Pika、Luma、Sora、Kling

## 使用方式

### 在 Mira 中使用

1. 将 `SKILL.md` 打包为 zip
2. 通过 Mira Skill API 上传创建

### 在其他 AI Agent 中使用

将 `SKILL.md` 的内容作为 system prompt 或 instructions 使用即可。
